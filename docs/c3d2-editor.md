# C3D2 Editor (Pygame)

`level_editor.py` остаётся редактором **legacy** `level_XX`/`tx*`/`sp*`.
Для новых C3D2 пакетов используется отдельный `scripts/c3d2_editor.py`.

```bash
# Рекомендуется: GUI + все форматы, которые умеет Pillow
python3 -m pip install -r requirements-editor.txt
# Эквивалентно: python3 -m pip install pygame pillow

# Открыть demo-пакет
python3 scripts/c3d2_editor.py res/gamedata/custom/demo

# Создать пакет в пустой папке
python3 scripts/c3d2_editor.py /path/to/my_map --new

# Проверить package без Pygame (подходит для CI)
python3 scripts/c3d2_editor.py res/gamedata/custom/demo --validate
```

`pygame` нужен только самому окну и 3D-пролёту. `Pillow` нужен для импорта
произвольных изображений; с ним доступны PNG, JPEG, WebP, TIFF, GIF, BMP, ICO
и другие поддерживаемые Pillow форматы. Без Pillow остаётся fallback для
обычных PNG через stdlib-декодер, но для «всех форматов» Pillow обязателен.
Ни Java ME runtime, ни C3B-компилятор не получают этих зависимостей.

## Что делает редактор

- открывает/сохраняет `level.c3d.json` и отдельный `entities.ini`;
- строит `level.c3b` (`F5`): BSP и PVS пересчитываются только при экспорте;
- показывает 2D карту, вершины, стрелки направлений стен, стены и entity;
- расставляет entity щелчком, переносит их drag-and-drop, редактирует
  `type`, `angle`, `param`;
- импортирует внешние изображения в нужный runtime BMP4 и автоматически
  обновляет `materials.c3m`;
- запускает Pygame 2.5D flythrough по C3D геометрии с portal-aware трассировкой
  лучей и текстурированными стенами.

## Управление 2D

| Клавиша / действие | Назначение |
| --- | --- |
| `1` | выбор/перетаскивание вершины или entity |
| `2` | создание стены: две точки/вершины |
| `3` | поставить entity в текущей позиции |
| `4`, `Delete` | удалить выбранную стену или entity |
| `N` | добавить сектор, копируя параметры активного |
| `B` | добавить/переназначить back-side выбранной стены в активный сектор |
| `Ctrl+S` | сохранить JSON и `entities.ini` |
| `F5` | сохранить и собрать C3B/BSP/PVS |
| `F3` | начать 3D пролёт |
| `I` | выбрать исходную картинку и импортировать материал |
| `M` | применить выбранный материал к стене/сектору |
| `R` | развернуть выбранную стену |
| `P` | переключить `main / upper / lower` часть стены |
| `H` | выбрать `floor / ceiling` у сектора |
| `[` / `]` | изменить material slot |
| `,` / `.` | изменить угол нового entity на 15° |
| `PageUp` / `PageDown` | изменить type нового entity |
| `G` | включить/выключить привязку к сетке |
| средняя/правая кнопка | панорамировать карту |
| колесо | масштабировать карту |
| `Enter` | числовое редактирование выбранного элемента |

Стрелка на стене — направление `start -> end`. Для `front` стороны сектор
должен быть справа от стрелки; внешний контур комнаты получается по часовой
стрелке. Если направление неверно, выделите стену и нажмите `R`, затем соберите
C3B: компилятор дополнительно проверит winding. Выбранный сектор становится
активным: новые стены получают его как `front`, а `B` добавляет для выбранной
стены обратную portal-сторону в активный сектор.

## Импорт текстур

Панель **Texture import** задаёт тип, slot, способ масштабирования и, для
стены, разрешение. Можно нажать `Import I`, перетащить файл в окно или выбрать
файл через системный диалог.

| Тип | Runtime размер | Куда пишется | Manifest key |
| --- | --- | --- | --- |
| wall | power-of-two ширина, высота `16/64/128` | `textures/wall_<slot>.bmp` | `wall.<slot>` |
| flat | `64x64` | `textures/flat_<slot>.bmp` | `flat.<slot>` |
| sky | `64x128` | `textures/sky.bmp` | `sky` |

Новый package сразу получает рабочие placeholder `wall.1`, `flat.1` и `sky`,
поэтому его можно собрать и открыть до импорта графики. Они лежат в
`textures/wall_1.bmp`, `textures/flat_1.bmp`, `textures/sky.bmp` и заменяются
безопасно при первом импорте в соответствующий slot.

Перед записью редактор:

1. масштабирует/обрезает изображение в target размер (`Fit`) либо растягивает
   его (`Stretch`);
2. композитит alpha на чёрный фон: материалы мира в Java ME непрозрачные;
3. запускает детерминированный weighted K-means на 16 RGB цветах;
4. записывает indexed BMP4 с 16 palette entries;
5. заменяет или добавляет запись в `materials.c3m`.

K-means реализован в `scripts/c3d2_texture_tools.py` на чистом Python, без
`numpy` и `scikit-learn`; это позволяет воспроизводимо получать те же BMP при
повторном импорте. Импорт выполняется только в редакторе, не в игровом кадре.

## Entity sidecar

Entity хранятся отдельно от геометрии:

```ini
[entities]
format=C3D-ENTITIES-1

[entity.0]
x=0
z=0
angle=0
type=1
param=0
```

Нужны `x`, `z`, `type`; `angle` и `param` имеют значение `0`, если не заданы.
Для запуска требуется хотя бы один spawn `type=1..4`. Изменение `entities.ini`
не требует пересборки BSP/C3B: файл всё равно должен быть перепакован в JAR,
но бинарная геометрия остаётся прежней.

Позиции обычных game object уже читаются из INI. Custom material pipeline пока
поставляет wall/flat/sky; отдельный pipeline для custom sprite assets врагов и
предметов — следующий этап, поэтому spawn-точки являются полностью готовым
сценарием сейчас.

## 3D пролёт

В 3D окне:

| Клавиша | Назначение |
| --- | --- |
| `W/A/S/D` | ходьба и strafe |
| `Q/E` или `←/→` | поворот камеры |
| `Shift` | быстрый ход |
| `R` | вернуться к spawn |
| `F3` или `Esc` | вернуться в 2D редактор |

Flythrough является быстрым Pygame-превью для авторинга: он проходит через
открытые порталы, блокирует выход за solid boundary и рисует wall BMP. Java ME
`PortalRenderer` остаётся окончательной runtime-проверкой, поэтому перед
релизом всегда запускайте собранный JAR.
